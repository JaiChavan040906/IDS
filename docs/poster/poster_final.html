Sentinel handles the traffic it is sure about, asks a security analyst about the rest, learns from verified decisions under fixed rules, and keeps a data warehouse of all its traffic for analysis.

How it works
01A flow arrives64 measurements of one conversation. No IPs or ports.
02CNN-LSTM classifiesNormal, or one of 12 attack types.
03Three checksHesitant? Unfamiliar? Second model disagrees?
04Route itSure: closed or alerted. Any doubt: analyst.
05Analyst decidesVerdict with reason, beside similar past cases.
Learning loop: verified analyst decisions → candidate model → deployed only if it passes rules set before training; one-click rollback.
